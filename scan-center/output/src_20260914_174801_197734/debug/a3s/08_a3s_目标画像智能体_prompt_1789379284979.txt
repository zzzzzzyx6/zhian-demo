- 当前环境允许多轮使用任意本地 CLI 工具，不预设命令类型白名单。
- agent 必须按目标形态、阶段职责和当前假设智能选择工具；不要把常见工具简单顺序调用一遍。
- 可考虑的工具类别包括静态安全规则、依赖/SBOM、密钥与配置扫描、二进制元数据/hardening、动态诊断、短预算 fuzz/随机输入、协议/API/基础设施检查和 Web 站点安全基线；这些只是启发，不是固定清单。
- 每次用工具前先明确要回答的问题；工具结果必须被解释，并影响候选、验证、驳回或下一步计划。
- scanner 命中、CVE 命中或可疑字符串只能作为线索；确认漏洞必须依赖可解释证据和影响判断。
- 只记录实际运行过的命令、预算、退出码和关键证据。
- 所有命令只能用于当前本地授权目标，必须限时、限资源、可停止、可清理；在线 Web 目标只允许授权 origin 的只读低强度探测。
