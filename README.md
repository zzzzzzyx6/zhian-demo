# 智安 AI 安全平台 Demo

完整的前端演示及构建源码，包含安全态势、安全扫描、模型演练、安全防护、策略中心、资产中心和风险中心。

## 使用

直接打开 `01-攻防演练中心/index.html` 使用当前融合版平台。根目录 `index.html` 保留原模块入口。

也可以在仓库根目录执行 `python -m http.server 8000`，再通过浏览器打开对应入口。无需安装前端依赖。

## 文件结构

- `01-攻防演练中心/`：当前融合版平台；`src/` 为源码，`scan-center/` 为融合的完整扫描页面及演示附件。
- `02-内容审核中心/`：独立内容审核演示。
- `03-漏洞扫描中心/`：原独立漏洞扫描演示。
- `dataset-sources/`、`range-source/`（位于平台目录）：使用的题库、来源说明及开源组件许可证。

修改平台源码后，执行 `python 01-攻防演练中心/build.py` 重建入口 HTML。

## 数据说明

演示状态保存在浏览器本地。内置任务、模型配置、响应摘要及扫描附件用于演示，不代表真实评估结果；浏览器本地状态和用户自行填写的凭证不会随代码上传。题库和组件保留各自的许可证及来源说明。

仓库仅包含演示、构建所需的代码、资源及来源文件，不包含本地调试截图、临时测试结果和开发环境配置。
