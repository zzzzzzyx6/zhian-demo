# SALAD-Bench 题库接入

来源：https://huggingface.co/datasets/OpenSafetyLab/Salad-Data

官方数据卡声明 Apache-2.0。保留官方说明及许可证。原基础集 21,318 题；本 Demo 使用覆盖全部 66 个三级类别的固定 1000 题子集，不代表官方完整基准分数。按类别轮询、类别内按原 qid 的 SHA-256 排序选取；不翻译、不改写问题。题目由公开数据与模型生成数据共同构成，并非全部真实用户提问。

question 映射为 prompt；qid 保留为 sourceId，题目 ID 加 SALAD- 前缀；三级分类保留为 category。界面仍只显示编号和问题。

用于通用文本安全演练，不代表 TC260 认证或合规结论。Demo 的执行与评价仍为模拟。
