### 标签的官方来源

参考现行 **GB/T 45654—2025《网络安全技术 生成式人工智能服务安全基本要求》**，2025-04-25 发布、2025-11-01 实施。

- [TC260 标准全文发布公告](https://www.tc260.org.cn/tc260/xwdt1/202506/739067714b9f40daa20219ea8fd7bf6d.shtml)
- [官方标准 PDF](https://www.tc260.org.cn/zgwabwuploadfile/1751257342816036759/1751257342816036759.pdf)
- 附录 A：印刷页 7–8（PDF 第 13–14 页），为**资料性附录**，共 5 大类、31 项内容风险。
- 附录 B.1.2：印刷页 9（PDF 第 15 页），生成内容测试题库应完整覆盖附录 A 的 31 种风险；B.1.4 同样提及分类模型覆盖范围。

| 标准大类 | 官方标题 | 选项数 |
| --- | --- | ---: |
| A.1 | 包含违反社会主义核心价值观的内容 | 8 |
| A.2 | 包含歧视性内容 | 9 |
| A.3 | 商业违法违规 | 5 |
| A.4 | 侵犯他人合法权益 | 7 |
| A.5 | 无法满足特定服务类型的安全需求 | 2 |

这不是“所有模型威胁”的统一目录。A.5 有安全需求较高的特定服务语境；不能把一般回答质量低直接当成该类。下拉中的 `gbt45654-*` 是本产品的稳定标识，不是标准发布的机器 key。每题保留对应标准名称和条款引用，不用标签或 ASR 自动生成“通过国标测评”结论。

常用八类、国标参考类、自定义类在下拉中分组；不自动把历史常用标签替换成国标标签，不以问题关键词猜测国标分类。原始题库 category 始终保留。

## 版本管理

采用与任务管理一致的筛选栏、表格、时间列排序、分页。只纳入任务中实际作为靶标的模型；列出模型版本、最终 ASR、对应演练任务和完成时间，提供演练记录及报告入口。不显示顶部总览、模型卡片、分数排名、默认分数排序或原型提示。

最终 ASR = 已攻破 / 有效判定；有效判定只包含已攻破和已守住。取最近一次已完成任务，未完成任务不生成最终 ASR。新增未完成任务不覆盖已有完成结果；历史记录可单独查看。

## 三种分类不能混用

| 维度 | 用途 | 判定依据 |
| --- | --- | --- |
| 模型系列／版本 | 汇总同一靶标身份的任务 | 任务保存的系列和版本；模型 ID 可辅助识别，不能解析 API Key 或仅凭 Base URL 推断 |
| 题库来源 | 题库检索和原始数据追溯 | 产品上只有内置／自建；保留题库名称、原始类别、来源与版本 |
| 攻击场景 | 题目与结果分析联动 | 原始分类映射或人工标签；与 Direct、PAIR 等攻击方法分开 |

API Key 是认证凭证；Base URL 是服务入口，同一网关可能同时提供多个模型系列。服务商不等于模型系列。

## 统一场景标签

常用场景提供违法犯罪、暴力与人身伤害、隐私与数据泄露、网络与系统安全、歧视与骚扰、色情与性安全、欺诈与虚假信息、专业建议与伦理八类；另提供上述 31 项国标参考标签和用户自定义标签。

- 优先用 JBB Category、HarmBench SemanticCategory、Safety-Prompts 原类别、SALAD 完整原始类别映射，不从问题词语或编号猜测。
- HarmBench 的 standard/contextual 等属于数据形态，不是风险场景；SALAD 的 O1 等编码仅在完整原标签匹配时识别。
- 无原分类的 AdvBench、泛化的 harmful，以及当前体系未明确覆盖的知识产权等类别保留待标注，不强塞进其他场景。
- 题库详情可按场景／题目搜索，逐题编辑多个场景。原始 category 保留，新增 sceneTags、sceneTagOrigin、sceneTagVersion。内置题库的人工作业保存为独立覆盖项，不改写上游数据文件。
- 新任务复制标签快照。修改题库标签不改变已保存的任务报告；历史无标签任务只根据自己的原始分类快照映射。
- 导入、导出与从任务提取题目保留场景标签。未知的合法标签名称转为自定义标签；非文本、空值、过长名称等格式错误仍会阻止导入。自定义名称和稳定 ID 随题目保存为 sceneTagDefinitions，标准参考随题目保存为 sceneTagReferences，跨导出导入可复原。
- 导入预览和已有题目共用下拉多选、自定义交互；未选择保持待标注。每题最多 20 个标签，自定义名称最多 32 字符，交互创建的自定义目录最多 200 个。

## 报告联动

报告为“指标摘要 → 核心发现 → 场景风险分析 → 攻击方法 → 重点证据 → 下一步建议 → 覆盖缺口”。报告 tab 不再重复上方的大块任务概览。

雷达图仅显示本任务关联场景的 ASR，无关场景不出现；无有效判定保持空值，不补成 0。少于三个有效场景或关联场景多于 12 个时使用逐项条形列表，避免拥挤雷达。多标签在各场景中分别统计，总体 ASR 不重复计数；每个场景同时展示有效／计划记录数。场景、核心发现和建议可下钻到对应场景及结果的攻防记录。记录详情显示原始题目编号、标签、响应与裁判证据。

HTML、打印和 Word 兼容导出使用同一份分析，增加完整攻破记录索引。没有证据或风险分级标准时不宣称已确认漏洞、严重级别或修复成功。

界面原型提示按要求删除；现有执行器和预设结果仍为本地模拟，底层 simulated 属性和原始证据保留。本次未调用真实模型，也不把预设结果作为公开模型能力比较。
